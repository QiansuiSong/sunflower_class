# 向日葵中班 V6.0

直接打开 `index.html` 即可游玩。游戏进度、事件收藏、结局图鉴和奖章图鉴均保存在浏览器本地。

## V6.0 更新重点

本版以 V5.1 为基础，保留结局判定修复、精力系统、自动存档和跨周目图鉴，重点重构角色故事。

### 角色设定统一

十二名角色的简介与事件行为已按最新版角色设定更新。事件不再把角色当作固定功能，而是根据各自性格、兴趣、关系和出现频率安排互动。

### 新增群像日常

新增或重写的内容包括：

- QAQ丨、馍馍、妮蔻、花花的多人游戏小组
- QAQ丨与蘑托车沉迷抓宠物游戏
- 点点主动提问、桃爸耐心拆解复杂规则
- 点点与花花截然相反的抽奖运
- 蘑托车、桃爸、馍馍的饮料讨论
- 辣条不能到场时托花花送甜点
- 小可爱的奇怪梦、收藏和营养饭习惯
- 小可爱持续照顾转学朋友留下的植物
- 欢佬从三分钟热度到持续练琴
- 西洲极少出现，但每次回来都能带动气氛
- 西洲替大家直接指出没人好意思说的问题
- 馍馍对真正小猫的期待
- 桃爸在材料不足时基于现实条件解决问题

### 连续故事与多周目

V6.0 新增跨周目连续支线框架：

- 植物：被照顾 → 长出新叶 → 多周目后开花
- 欢佬练琴：开始认真练习 → 多周目后仍然坚持
- 游戏组：第一次新游戏 → 多周目后的熟悉感
- 西洲：偶尔回来 → 又一次长时间缺席与回归痕迹

这些后续事件会读取跨周目事件收藏和已完成学期数。旧版 V5.1 存档与收藏键保持不变。

# 向日葵中班 Ver.0.2.1 长期养成版

## 部署
将 `index.html` 上传到 GitHub Pages 或任意静态网页空间即可。

## 本次修正
- 行动名称恢复为“玩皇后养成计划”。
- 只要当前行动或未开始队列中仍有该安排，且本时段氛围未满3点，小游戏会显示“QAQ丨正在观看你游戏”。
- 合成皇后时，本时段首次弹出“QAQ丨：简单。”。
- 本时段氛围达到3点后，首次继续游戏会提示QAQ丨已经看够，但玩家仍可自行游玩。
- 清空未开始项目时，如果最后一个观看安排被删除，本时段尚未结算的氛围会失效。
- 成员界面只显示已经加入的角色；点点及其加入条件在加入前完全隐藏。

## 主要功能
- 06:00 / 18:00 两个现实时间节点。
- 每项行动真实耗时30分钟，关闭页面后继续计时。
- 心情、阴阳师熟练度、羁绊。
- 心情3/12节点增加每时段安排次数。
- 阴阳师6/24节点提高饭产出。
- 皇后养成计划始终可玩；仅在QAQ丨观看时产生养成收益。
- 每时段最多获得3点隐藏氛围。
- 饭、剩饭、点点加入与成长。
- localStorage自动存档与JSON导入导出。

## 注意
- 时间以设备本地时间为准。
- 修改设备时间可能影响结算，本版本不做联网防作弊。
- 氛围值和点点加入条件按设计保持隐藏。

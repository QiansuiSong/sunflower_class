# 向日葵中班·多周目系统重制版 v5

直接打开 `index.html` 即可游玩。当前学期进度与跨周目收藏均保存在浏览器本地。

## 本版主要变化

### 故事不再全部圆满

新增幼儿园尺度的复杂情绪事件，包括：

- 只有一幅画受到表扬时产生的嫉妒
- 小摆件被踩坏后没人承认
- 小团体游戏没有邀请所有人
- 答应朋友的事情被忘记

选项不保证存在完美答案。有些选择会照顾一个人却让另一个人失落，也可能解决眼前问题但留下尚未消除的隔阂。

### 结局重新扩写

- 主要结局由一句抽象说明改为完整的学期收束
- 结局会回顾玩家形成的路线、关系变化和开放日结果
- 新增 2 个需要完成多轮游戏才可能解锁的隐藏结局

### 多周目内容

- 完成 2、3、4 个以上学期后，会逐步出现特殊事件
- 部分特殊事件还要求收集一定数量的普通事件或结局
- 新增的特殊内容不会在第一轮出现

### 图鉴

开始页面和结算页面均可打开“结局与奖章图鉴”，查看：

- 已经解锁的主要结局及完整文案
- 尚未解锁的结局位置
- 已经取得过的奖章
- 当前完成周目数与收集进度

### 奖章精简

- 每局结算最多展示并取得 2 枚最具代表性的奖章
- 不再一次列出大量相似奖章
- 历史奖章可在图鉴中查看

### 精力系统重做

精力上限为 8，且不会每天自动恢复：

- 收拾教室：-2
- 课间游戏：-2
- 大型手工：-3
- 悄悄聊天：-1
- 主动休息：+3

部分剧情选择也会额外消耗精力。玩家需要在能力成长、关系推进与后半段行动空间之间进行取舍。

## v5.1 结局判定修复

- 基础结局不再按固定优先级依次截断。
- 体贴、靠谱、灵感、勇气会根据属性、日常行动和关键选择分别计算路线分数。
- 友情结局只有在关系明显集中于单一角色时才参与判定。
- 普通结局只在各项路线较均衡、没有明显倾向时出现。
- 当多个结局路线分数接近时，优先选择尚未收集的结局，帮助多周目解锁图鉴。
- 稀有连续剧情和多周目结局仍优先，但同一局满足多个时也优先发放尚未解锁者。

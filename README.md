# 向日葵中班·剧情版 v2

直接打开 `index.html` 即可游玩。进度与跨周目收藏均保存在浏览器本地。

## 本版内容

- 18 天一学期，单局约 15～25 分钟
- 12 名角色与独立关系值
- 38 个不同事件：26 个普通/主线事件，12 个条件后续事件
- 12 个互斥的主要结局，每局只获得一个
- 20 个可叠加收集的班级奖项
- 事件、结局、奖项跨周目收藏进度
- 新周目优先抽取玩家尚未看过的可触发事件
- 自动本地存档，可在手机和电脑浏览器游玩

## 文件结构

- `index.html`：页面入口
- `style.css`：界面样式
- `data.js`：角色、事件、结局、奖项等内容
- `game.js`：流程、判定、存档与收藏机制
- `DESIGN.md`：长期设计说明
- `README.md`：运行说明

内容扩充原则上继续集中修改 `data.js`，不要随意增加文件。
